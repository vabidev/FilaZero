# 📅 FilaZero - Sistema de Agendamento Online

Sistema completo e profissional de agendamento online para barbearias, salões, clínicas e profissionais autônomos.

> **🎁 COMPROU O FILAZERO?** Comece lendo o arquivo [COMECE-AQUI.md](COMECE-AQUI.md)!

## 🚀 Início Rápido

```bash
# Instalar dependências
npm install

# Iniciar servidor
npm start
```

Acesse:
- **Site**: http://localhost:3000
- **Admin**: http://localhost:3000/admin
  - Usuário: `admin`
  - Senha: `admin123`
