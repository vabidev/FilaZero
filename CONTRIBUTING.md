# Contribuindo com o FilaZero

Obrigado por contribuir com o FilaZero.

## Como colaborar

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Mantenha as mudanças pequenas e objetivas.
4. Teste a aplicação localmente.
5. Abra um pull request explicando o problema e a solução.

## Desenvolvimento

```bash
npm install
cp .env.example .env
npm run dev
```

Não envie arquivos `.env`, bancos SQLite, credenciais, tokens, dados de clientes ou outros segredos.

Ao contribuir, você concorda que sua contribuição será distribuída sob a licença MIT do projeto.
